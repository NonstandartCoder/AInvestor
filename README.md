# AInvestor

AI agent, который помогает инвестировать постоянно, без необходимости самостоятельного мониторинга.
В тоже время инструмент предполагается достаточно гибким, самостоятельность агента будет настраиваемой.

# Запуск проекта.

Проект будет основан на uv. Запуск проекта предполагается полностью локальным и основанным на локальных моделях.
Однако также можно и добавить API.
