# AInvestor

AI agent, который помогает инвестировать без необходимости самостоятельного мониторинга новостей, отчетов и других источников.
В тоже время инструмент предполагается достаточно гибким, степень самостоятельности агента будет настраиваемой.
В 1 итерации преподлагается лишь выдача определенных прогнозов на некоторый горизонт. На данном этапе проект рассматривается
лишь для личного использования и выдача предсказаний не является инвестиционной рекомендацией в смысле 39-ФЗ «О рынке ценных бумаг».

# Запуск проекта.

Проект будет основан на uv. Запуск проекта предполагается полностью локальным и основанным на локальных моделях.
Однако также можно и добавить API.
