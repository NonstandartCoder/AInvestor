# AInvestor

AI agent, который помогает инвестировать без необходимости самостоятельного мониторинга новостей, отчетов и других источников.
В тоже время инструмент предполагается достаточно гибким, степень самостоятельности агента будет настраиваемой.
В 1 итерации преподлагается лишь выдача определенных прогнозов на некоторый горизонт. На данном этапе проект рассматривается
лишь для личного использования и выдача предсказаний не является инвестиционной рекомендацией в смысле 39-ФЗ «О рынке ценных бумаг».

## Запуск проекта

Проект основан на [uv](https://docs.astral.sh/uv/) и Docker. Запуск предполагается полностью локальным, на локальных моделях.
При необходимости можно подключать внешние API (MOEX ISS, CBR, новостные RSS) — ключи прокидываются через `.env`.

### Через Docker (рекомендуется)

~~~bash
# 1. Сборка и запуск контейнера в фоне
docker compose up -d --build

# 2. Войти в контейнер для интерактивной работы
docker compose exec AInvestor bash

# 3. Запуск EDA-скриптов внутри контейнера
uv run python app/eda/01_fetch_moex_ohlcv.py    # загрузка OHLCV с MOEX ISS API
uv run python app/eda/02_eda_analysis.py        # очистка, adjustment, визуализации, отчёт

# Остановить контейнер
docker compose down
~~~

Bind mount `./app:/srv/project/app` пробрасывает исходный код с хоста в контейнер —
правки в `app/` видны сразу без пересборки. Пересобирать образ нужно только при изменении
`pyproject.toml` / `uv.lock`.

### Локально без Docker

Если uv уже установлен на хосте (Python 3.12+):
~~~bash
uv sync --group eda --group dev
uv run python app/eda/01_fetch_moex_ohlcv.py
uv run python app/eda/02_eda_analysis.py
~~~

### Переменные окружения

Перед запуском создайте `.env` в корне репозитория (см. `.env.example`):

~~~dotenv
# MOEX ISS API не требует ключа, но при наличии повышает rate-limit
MOEX_ISS_TOKEN=

# Таймзона для дат в данных
TZ=Europe/Moscow
~~~

## EDA — ключевые находки

Период: 2023-01-03 … 2025-11-13 (~746 торговых дней). 15 тикеров MOEX (топ IMOEX по ликвидности).

- **Объём**: 10 582 сырых строк; после dropna по close = 10 240; дубликатов 0.
- **Корпоративные действия** (3 события): GMKN 2024-04-08 (-99% split), PLZL 2025-03-27 (-90% split), VTBR 2024-07-15 (+466 200% reverse-split/aggregation). MOEX ISS не делает price-adjustment — реализован `forward-adjust` по `ratio = close_after / close_before` в `app/eda/02_eda_analysis.py` секция 3.
- **YDEX**: только 348 строк с 2024-07-08 (после редомициляции Yandex NV → YDEX).
- **Cross-ticker корреляция**: средняя 0.538, максимум SBER↔YDEX = 0.795 — типично для MOEX; ограничивает ценность purely price-based фичей.
- **Распределение доходностей**: mean +0.029%/день, std 1.93%/день (annualized vol 30.7%), kurtosis 6.45 (тяжёлые хвосты).
- **Направления** (fwd-1d, порог flat ±0.5%): up 34.5% / flat 29.7% / down 35.8% — class imbalance.
- **Оборот**: ~50 млрд ₽/день по 15 тикерам; ликвидность достаточна для paper trading с депозитом 300 000 ₽.
